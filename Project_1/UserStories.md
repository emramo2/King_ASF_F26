# Neon Black Market - User Stories

## User Story 1
Fragment:
"This sucks. I have to log in every five minutes."

User Story:
As a user, I want my login session to remain active so I do not have to constantly log in while using the system.

---

## User Story 2
Fragment:
"Why can I not see my past purchases?"

User Story:
As a user, I want to view my purchase history so I can track everything I have bought.

---

## User Story 3
Fragment:
"My listing disappeared again."

User Story:
As a vendor, I want my product listings to remain available so customers can continue purchasing them.

---

## User Story 4
Fragment:
"I want to read reviews before buying."

User Story:
As a customer, I want to read reviews before purchasing a product so I can make better buying decisions.

---

## User Story 5
Fragment:
"Transactions must link users and products."

User Story:
As a system administrator, I want every transaction linked to both a user and a product so the database remains accurate and complete.
